# Licensing

First-party software, workflows and scripts are `MIT OR Apache-2.0`, at the
recipient's choice. Documentation prose is `CC-BY-4.0`; code examples follow
the software license. Full terms are in [LICENSES/](LICENSES/).

Contributions use those existing licenses. No CLA or DCO is required.
Contributors retain their copyright. Keep applicable third-party notices.

The reusable source is public. Its license does not authorize access to private
test suites, host configuration, credentials or other projects. Each project
keeps its own license and publication policy.
